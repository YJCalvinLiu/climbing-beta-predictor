# climbing-beta-predictor

A computer vision + machine learning project to analyze indoor climbing route images and suggest the best beta (optimal path + optimal sequence).

## 🚨CURRENTLY WORKING ON🚨 Annotating data set (climbing wall images with multiple routes) 


## Project Goals
- Detect climbing holds from gym wall images.
    - Identify by color
    - Identify by hold type (e.g Jug , Sloper , Crimp etc)
      
- Model optimal movement sequences between holds.
    - Output a list of moves "Beta"
